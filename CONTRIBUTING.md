# Как опубликовать плагин Ovygram

Каталог наполняется сервером реестра после модерации. Чтобы подать плагин,
отправьте файл [боту @OvygramApp](https://t.me/OvygramApp) со своего
Telegram-аккаунта. Авторство определяется аккаунтом отправителя.

## Форматы

- `.ovyplugin` — один Python-файл с метаданными.
- `.ovyzip` — ZIP-пакет с `plugin.json`, основным Python-файлом и ресурсами.

Назовите файл по ID: например, `chat_tools.ovyplugin`.
Объявите метаданные один раз, простыми литеральными присваиваниями:

```python
__id__ = "chat_tools"
__name__ = "Chat Tools"
__description__ = "Что делает плагин и как им пользоваться."
__author__ = "Your Name"
__version__ = "1.0.0"
__release__ = True
__platform__ = "desktop"
__desktop_sdk__ = 2
__requirements__ = []
```

Используйте ID из строчных латинских букв, цифр и `_`, длиной до 25 символов.
Публичный ID закрепляется за одним автором. Версия обновления должна иметь
большую числовую часть или ту же числовую часть с другим буквенным суффиксом
по правилам реестра. Имя автора `Ovygram` зарезервировано.

В корне `.ovyzip` нужен `plugin.json`:

```json
{
  "id": "chat_tools",
  "entry": "main.py"
}
```

- [Шаблон проекта](https://github.com/Ovygram/Ovygram/tree/main/tools/ovygram/template)

## Модерация и публикация

Бот проверяет структуру и метаданные без выполнения кода, затем передаёт
заявку проверяющим. Отправитель получает решение; при отказе указывается
причина. Публичная одобренная версия попадает в GitHub после успешной
загрузки и проверки точных байтов.

Не добавляйте исполняемые пакеты и записи индекса вручную через pull request:
это не создаёт одобрения в реестре. Исправления документации можно предлагать
через pull request. Не прикладывайте токены, ключи подписи, `.env`, данные
Telegram-сеанса или пользовательские данные.
